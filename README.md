# Study-vault

An offline-first Flutter application designed for students to organize study materials systematically into courses, semesters, and subjects.

## Key Features
- **Hierarchical Organization:** Structure files under Course → Semester → Subject.
- **Multiple Category Support:** Separate sections for Books/PDFs, Notes, Question Papers, PPTs, and Images.
- **In-App Search & Sorting:** Locate files quickly by subject or category; sort by date, name, or size.
- **Local Persistence & Favorites:** Star critical materials and store documents directly on the device.

## Built With
- **Framework:** Flutter (Dart)
- **State Management & Storage:** `ChangeNotifier`, local JSON storage, and `path_provider`
- **File Handling:** `file_picker`, `open_filex`
